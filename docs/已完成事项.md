## 五、冒烟发现并修复的关键缺陷(真机验证)

| # | 缺陷 | 修复 |
|---|------|------|
| 1 | SPA 跳转后内容区空白(App.vue `mode="out-in"` 与懒加载组件组合) | 带 key 的 plain transition;旧页 `display:none` 瞬卸 |
| 2 | 存量文档全部不可读(V5 之前 content 为 NULL) | content 接口惰性回填(原文件在磁盘即重提取落库) |
| 3 | PDF iframe 被 Spring Security `X-Frame-Options: DENY` 阻断 | 改 `SAMEORIGIN` |
| 4 | 知识库「全部文档」模式点文档无反应 | 入口改用文档自身 kbId |
| 5 | h4+ 标题导致 Markdown 锚点 id 错位 | 渲染规则跳过 h4+,与大纲提取对齐 + 回归测试 |
| 6 | 高亮样式多轮切换失效(Vite 动态 CSS import 缓存) | `?inline` 文本 + 单 style 管理 + 多轮切换测试 |
| 7 | discrete api 弹层随主题切换泄漏容器 | 重建前 `unmount()` + 泄漏测试 |
| 8 | 星标/铅笔点击冒泡误开会话(嵌套 button 非法) | 内层改 span + `@click.stop` |
| 9 | 流式消息 id=0 永久不可反馈 | 流式成功结束自动回填服务端 id |
| 10 | README 端口错误(前端写成 8080) | 修正为前端 80 / 后端 8080 |
| 11 | 测试库跨用例/跨类遗留数据导致假失败 | 统一 `@BeforeEach` 隔离(任务/新闻/收藏文档/源启停) |
| 12 | 日报 RUNNING 拒重竞态、收藏无去重、last_crawl 全表误更 | 原子 INSERT、sourceUrl 查重、按源更新 |
